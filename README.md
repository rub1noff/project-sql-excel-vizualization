# Анализ вакансий аналитиков данных

Учебный проект: анализ рынка вакансий аналитиков по таблице `parcing_table` (1801 вакансия, публикации с 13.02.2024 по 11.06.2024). Данные исследованы SQL-запросами (PostgreSQL), результаты оформлены в Excel с графиками.

**Стек:** SQL, Excel.

## Описание таблицы

| Столбец | Тип данных | Описание |
|---|---|---|
| `id` | int4 | Идентификатор объявления (первичный ключ) |
| `name` | varchar | Название вакансии |
| `published_at` | timestamp | Дата выставления вакансии |
| `employer` | varchar | Компания, которая ищет работника |
| `department` | varchar | Отделение компании, в котором необходим сотрудник |
| `area` | varchar | Расположение компании |
| `experience` | varchar | Необходимый опыт и ранг кандидата (грейд) |
| `schedule` | varchar | График работы |
| `employment` | varchar | Занятость: полная или частичная |
| `salary_from` | numeric | Заработная плата в категории «от» |
| `salary_to` | numeric | Заработная плата в категории «до» |
| `salary_bin` | varchar | Заработная плата в категории «зарплатная вилка» |
| `key_skills_1` … `key_skills_4` | varchar | Первый … четвёртый ключевой (хард) навык, который требуется от кандидата |
| `soft_skills_1` … `soft_skills_4` | varchar | Первый … четвёртый дополнительный (софт) навык, который требуется от кандидата |

## Выводы

**Рынок сконцентрирован в двух городах.** Москва даёт 69% всех вакансий (1247), Санкт-Петербург 10% (181). Вместе это 79%. Дальше с большим отрывом идут Екатеринбург (51), Новосибирск и Нижний Новгород (по 33).

**Один работодатель заметно выделяется.** На Сбер приходится 243 вакансии, то есть 13,5% рынка. Следом идут Wildberries (43), Ozon (34), ВТБ (28) и Т1 (26). Топ-5 компаний даёт около 21% вакансий. Среди чисто аналитических вакансий лидеры те же: Сбер, Ozon, ВТБ, Т1 и Центральный банк.

**Типичное место работы аналитика:** полная занятость (98% вакансий) и полный рабочий день (82% аналитических вакансий). Удалённая работа встречается в 15% аналитических вакансий (17% по всей таблице).

**Грейд.** Больше всего вакансий для кандидатов с опытом 1-3 года (Junior+): 61% по всей таблице и 64% среди аналитических. Middle занимает 26%, Junior без опыта 9%, Senior всего 0,5% (6 вакансий). Рынок ориентирован на начинающих специалистов с небольшим опытом, а позиций для опытных очень мало.

**Хард-скиллы.** Самый востребованный навык — SQL: он упомянут в 42% вакансий, если смотреть все четыре колонки навыков. Далее идут Python (25%), «Анализ данных» (22%), «Документация» (13%), Power BI (10%) и Pandas (9%). Если смотреть только `key_skills_1`, как в исходном запросе, SQL выглядит заметно слабее (161 упоминание вместо 760), потому что он чаще стоит не на первом месте.

**Софт-скиллы.** Чаще всего указывают документацию (16%), коммуникацию (10%) и аналитическое мышление (8%). Софт-скиллы указаны всего в трети вакансий.

**Зарплаты.** Среднее по вакансиям с указанной зарплатой: около 110 тыс. ₽ в `salary_from` и около 154 тыс. ₽ в `salary_to` (медиана 90 и 120 тыс. ₽). Зарплата растёт с грейдом: медиана `salary_from` составляет около 60 тыс. ₽ для Junior, 90 тыс. ₽ для Junior+ и 150 тыс. ₽ для Middle. Для Senior выборка слишком мала (3 вакансии), поэтому цифре доверять нельзя.
